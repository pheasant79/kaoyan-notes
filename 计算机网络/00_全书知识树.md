## 题型与过程入口

- <span style="color:#269c72"><strong>时延/速率：</strong></span>先拆传播、传输、处理、排队，再统一单位；见[第1章](01_计算机网络体系结构.md#examples)。
- <span style="color:#269c72"><strong>CRC/窗口：</strong></span>先确定帧边界、序号空间和确认规则，再逐步模拟；见[第3章](03_数据链路层.md#examples)。
- <span style="color:#269c72"><strong>子网/路由：</strong></span>先写二进制掩码，再算网络范围，最后按最长前缀匹配；见[第4章](04_网络层.md#examples)。
- <span style="color:#269c72"><strong>TCP：</strong></span>先区分序号、确认号、接收窗口和拥塞窗口，再判断状态或发送范围；见[第5章](05_传输层.md#examples)。
- <span style="color:#269c72"><strong>应用访问：</strong></span>先判断名称解析、连接建立和应用请求的先后关系；见[第6章](06_应用层.md#examples)。

## 易混边界

| 易混对象 | 区分要点 |
|---|---|
| 服务、接口、协议 | 服务是向上提供的功能，接口是调用边界，协议是通信双方遵守的规则 |
| 传输时延、传播时延 | 前者由数据量和发送速率决定，后者由距离和信号传播速度决定 |
| MAC 地址、IP 地址、端口 | 分别定位相邻接口、网络主机、主机内进程 |
| 链路可靠性、TCP可靠性 | 前者只覆盖相邻节点，后者覆盖端到端进程通信 |
| 路由、转发 | 路由计算路径，转发依据表项逐跳发送分组 |
| DNS、DHCP、ARP | DNS解析名称，DHCP配置网络参数，ARP解析同一链路上的IP到MAC；DHCP主归应用层，ARP是网络—链路边界 |
| 流量控制、拥塞控制 | 流量控制保护接收方，拥塞控制保护网络 |

现代扩展（IPv6、HTTP/2/3、QUIC、CDN、SDN）仅在相关章节的短注中出现，不改变主线。
