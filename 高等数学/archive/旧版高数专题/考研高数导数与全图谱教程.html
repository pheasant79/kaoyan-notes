考研高数：导数急救与全图谱教程

给现在“看到 x'、dx、dv 就乱”的阶段用。先把符号地基打稳，再把考研高数各章放进一张地图里。

0先把混乱停住：导数只问一件事

导数的核心问题 某个量随着另一个量变化时，变化得有多快。必须同时说清楚：谁是函数，谁是自变量。
导数 = 因变量的微小变化 / 自变量的微小变化 如果 y = f(x)，那么 y' 通常表示 dy/dx。 如果 x = x(t)，那么 x' 通常表示 dx/dt。 如果没有说“对谁求导”，x' 这个符号本身是不完整的。

1x' 到底是什么：不是固定答案

你见过 x'=0，也见过 x'=x^2，并不矛盾。它们说的是不同语境。

写法完整意思为什么
x' = 0dx/dt = 0，x 对 t 是常数例如 x=3，t 怎么变，x 都不变
x' = 1dx/dx = 1x 对自己求导，每增加 1，自己也增加 1
x' = 2tdx/dt = 2t，且 x=t^2x 是 t 的函数
x' = x^2dx/dt = x^2这是微分方程，不是普通求导结果，意思是“x 的变化率等于 x²”
一句话定心 ' 是省略写法。省略之前必须知道自变量是谁。考研题里若写 y'，默认多半是 dy/dx；若写运动、微分方程里的 x'，多半是 dx/dt。

2dx、dv、微分：它不是“随便消去”

如果 v=x+1，我们写 dv=dx；如果 v=x^2，写 dv=2x dx。原因不是“把 t 消掉就行”，而是微分定义。

若 v = f(x) dv = f'(x) dx v = x + 1 → dv = 1·dx = dx v = x² → dv = 2x·dx
导数写法 dv/dx = 2x 表示 v 对 x 的变化率。
微分写法 dv = 2x dx 表示 v 的微小变化约等于 2x 倍的 x 的微小变化。
不要写成 v'=2x dv/dx 如果 v'=dv/dx，那已经等于 2x 了；再乘一个 dv/dx 就重复了。正确链条是：dv/dx=2x，所以 dv=2x dx。

3链式法则与换元积分：t 不是被魔法消掉

当 v=f(x)，而 x=x(t) 时，v 间接依赖 t。此时：

v = f(x), x = x(t) dv/dt = dv/dx · dx/dt 例如 v=x²: dv/dt = 2x · dx/dt

如果两边都乘 dt，得到：

dv = 2x · dx

这就是为什么换元积分里可以写 v=x², dv=2x dx。它不是“左右各自随便挑一个导数”，而是链式法则背后的统一结果。

4你提到的三个误区，逐个纠正

误区 1：x' 有固定值 没有。x' 必须看对谁求导。dx/dx=1，但 dx/dt 可能是 0、2t、x² 或别的。
误区 2：等式右边只要能反映变化就行 不行。必须变量关系明确。dv/dt = dv/dx · dx/dt 是链式法则，不是随意拼接。
误区 3：导数左边关于 v，右边关于 x，所以要写 v'=2x dv/dx 正好相反：dv/dx 本身就是“v 关于 x 的导数”。若 v=x²，则 dv/dx=2x。
误区 4：x' · dx = x 一般不成立。若 x'=dx/dt，则 x' dx=(dx/dt)dx，没有理由等于 x。你可能想起的是 ∫1 dx=x+C 或 d(x²/2)=x dx。
遇到任何导数符号，先补全 把 ' 改写成分式：y' 改成 dy/dx，x' 改成 dx/dt 或题目给定的自变量。补全以后，很多混乱会自己消失。

6积分：它和导数是一对反向工具

不定积分是在找原函数，定积分是在算累积量。考研里不要只背公式，要先判断类型。

积分类型常见信号常用方法
凑微分里面有复合函数，外面有其导数影子u=g(x), du=g'(x)dx
分部积分乘积，尤其多项式乘三角/指数/对数∫u dv=uv-∫v du
有理函数分式多项式拆分、配方、部分分式
定积分性质区间对称、含 a+b-x换元、奇偶性、周期性
反常积分无穷区间或无界函数先写极限，再判敛散
积分换元的本质 不是“把 dx 换掉就行”，而是用微分关系替换整块：若 u=g(x)，则 du=g'(x)dx。必须整块匹配。

7极限与连续：高数第一地基

知识点核心问题常用方法
数列极限n 趋于无穷时靠近谁夹逼、单调有界、等价无穷小思想
函数极限x 靠近某点或无穷时函数靠近谁代入、因式分解、洛必达、泰勒
无穷小比较谁比谁小得更快等价替换：sin x~x，1-cos x~x²/2
连续函数值等于极限值左极限=右极限=函数值
考研经验 极限题不是都用洛必达。能等价替换就替换，能泰勒就泰勒，复杂乘除再考虑洛必达。

8级数、多元函数、空间解析几何

级数 正项级数判敛散，交错级数看莱布尼茨，幂级数重点是收敛半径、收敛域、展开与求和。
多元函数微分 偏导、全微分、复合函数求导、隐函数求导、极值与条件极值。核心是变量关系图。
二重积分 先画区域，再定积分次序。直角坐标适合矩形/上下边界，极坐标适合圆、扇形、含 x²+y²。
空间解析几何 向量、平面、直线、曲面。重点是会把几何条件翻译成方程。

9微分方程：x'=x² 这类式子的归宿

x'=x² 不是“x 求导等于 x² 的普通公式”，它是在规定未知函数 x(t) 应该满足的变化规律。

类型样子方法
可分离变量dy/dx=g(x)h(y)把 y 放一边，x 放一边，积分
一阶线性y'+P(x)y=Q(x)公式法或常数变易法
二阶常系数齐次y''+py'+qy=0特征方程
二阶常系数非齐次y''+py'+qy=f(x)通解=齐次通解+特解
例：dx/dt = x² 分离变量： dx/x² = dt 两边积分： -1/x = t + C 所以： x = -1/(t+C)

10考研高数全图谱：先知道自己在哪

板块核心能力你现在要怎么学

你现在的优先级 先不用追求“所有题都会”。先把导数、微分、链式法则、换元积分这条线打通。它贯穿极限、积分、多元、微分方程，属于地基里的地基。
