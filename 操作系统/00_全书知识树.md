## 方法选择入口

- <span style="color:#269c72"><strong>调度题：</strong></span>先画到达时间和服务时间，再画甘特图，最后计算周转时间、带权周转时间和响应时间。
- <span style="color:#269c72"><strong>同步与死锁题：</strong></span>先写共享约束和信号量初值，再逐步核对 P/V 顺序；银行家题按 Need、Work 和安全序列推进。见[第3章同步短例](03_同步与死锁.md#examples)与[银行家算法](03_同步与死锁.md#banker)。
- <span style="color:#269c72"><strong>地址转换题：</strong></span>先拆页号/页内偏移，查 TLB，再查页表；出现无效位时转入缺页处理。见[第4章地址转换短例](04_内存管理.md#examples)。
- <span style="color:#269c72"><strong>置换与内存分配题：</strong></span>明确页框数和初始状态，逐次处理访问串并记录缺页次数；另分清局部/全局置换与页框分配。见[第4章页面置换短例](04_内存管理.md#replacement)。
- <span style="color:#269c72"><strong>文件分配题：</strong></span>先判分配方式，再用逻辑块号和块内偏移定位；多级索引按每层地址项数逐层展开。见[第5章文件块定位](05_文件系统.md#block-location)。
- <span style="color:#269c72"><strong>位示图题：</strong></span>先确认位序和 0/1 含义，再分配并更新位图。见[第5章短例](05_文件系统.md#examples)。
- <span style="color:#269c72"><strong>磁盘调度与 DMA 题：</strong></span>磁盘题先确认初始磁头和扫描方向；DMA 题依题设计算传送字数、总线周期和占用比例。见[第6章磁盘调度](06_输入输出系统.md#disk-scheduling)与[DMA 短例](06_输入输出系统.md#examples)。

## 易混边界

| 易混对象 | 区分要点 |
|---|---|
| 程序 / 进程 | 程序是静态指令集合，进程是执行中的程序及其状态、资源和 PCB |
| 系统调用 / 普通函数 | 系统调用跨越用户态—内核态边界，普通函数不必进入内核 |
| 就绪 / 阻塞 | 就绪是等待 CPU，阻塞是等待事件或资源 |
| 分页 / 分段 | 分页按固定大小物理管理，分段按逻辑意义划分地址空间 |
| 文件逻辑结构 / 物理结构 | 前者面向用户组织数据，后者描述磁盘块如何存放 |
| 中断 / DMA | DMA 负责批量搬运，通常以中断通知 CPU 完成 |
