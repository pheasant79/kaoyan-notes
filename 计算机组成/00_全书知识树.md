## 方法入口

- <span style="color:#16A34A"><strong>数据表示题：</strong></span>先确认位数和编码，再运算，最后检查范围、溢出、规格化和舍入。
- <span style="color:#16A34A"><strong>存储题：</strong></span>先统一地址单位，再区分容量、字长、地址位数，最后画译码、Cache 或页表链。
- <span style="color:#16A34A"><strong>指令题：</strong></span>先拆字段，再判断寻址方式、有效地址和访存次数。
- <span style="color:#16A34A"><strong>CPU 题：</strong></span>按寄存器读写、ALU 操作、访存和写回列出微操作。
- <span style="color:#16A34A"><strong>I/O 题：</strong></span>按数据量、事件模式、CPU 参与程度和总线占用选择查询、中断或 DMA。

## 易混边界

| 易混对象 | 一句话区分 |
|---|---|
| MAR / MDR | MAR 保存访问地址，MDR 保存读写数据 |
| 存储单元 / 存储字 | 前者是可编址位置，后者是一次读写的数据单位 |
| 立即 / 间接寻址 | 字段本身是操作数 / 字段还要指向地址 |
| 取指访存 / 执行访存 | 取指得到指令，执行访存得到操作数或写回数据 |
| 带宽 / 总线宽度 | 单位时间传输量 / 一次并行传输位数 |
| 中断 / DMA | 中断改变控制流，DMA 主要搬运数据 |

## 模型边界

正文以 408 常用抽象模型为主。Cache、TLB、流水线和现代控制器实现只用于解释层次或易混点；遇到具体题目时，以题干给出的部件、时序和传输约定为准。
