# 《数据结构》全书总览

<span style="color:#2563EB"><strong>核心用法：</strong></span>
先在本页定位名词，再跳到对应章节的知识标题。总览负责“它属于哪里”，章节负责“它是什么、怎么用、代价如何”。

## 全书主线

数据结构不是把术语堆在一起，而是沿着四个问题展开：

1. **数据之间是什么关系？**  
   集合、线性、树形、图状。
2. **这些关系如何表示？**  
   顺序、链式、索引、散列等存储方式。
3. **对数据要做什么？**  
   访问、插入、删除、查找、遍历、排序。
4. **怎样评价做法？**  
   正确性、适用条件、时间复杂度、空间复杂度和稳定性。

## 建议复习顺序

1. 第1章：先建立“逻辑结构—存储实现—算法—复杂度”的坐标系。
2. 第2、3、4章：掌握线性结构、受限线性结构和字符匹配。
3. 第5、6章：掌握树和图，并理解遍历工具如何迁移到复杂问题。
4. 第7章：把树、索引和散列放回“定位记录”的任务中。
5. 第8章：按排序机制、复杂度、稳定性和适用场景比较算法。

<span style="color:#8B5CF6"><strong>跨章主线：</strong></span>
第1章提供分析语言；第2—6章提供结构与工具；第7章解决定位；第8章解决重排。不要把章节之间的箭头理解成“前一章自动变成后一章”，而要理解成“后续章节复用前面的概念”。
