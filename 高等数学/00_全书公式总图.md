## 方法选择入口

- <strong style="color:#16A34A">极限：</strong>先代入 → 判断未定式 → 因式分解/有理化/等价替换/夹逼/洛必达；见[第1章方法](01_函数与极限.md#limit-methods)。
- <strong style="color:#16A34A">求导：</strong>先拆结构 → 基本公式 → 链式法则 → 检查变量依赖；见[第2章](02_导数与微分.md#derivative-rules)。
- <strong style="color:#16A34A">积分：</strong>先看结构 → 直接积分/换元/分部/部分分式；见[第4章](04_不定积分.md#method-choice)。
- <strong style="color:#16A34A">导数应用：</strong>定义域 → 驻点和不可导点 → 符号表 → 单调、极值、凹凸；见[第3章](03_中值定理与导数应用.md#application-flow)。
- <strong style="color:#16A34A">重积分：</strong>画区域 → 选切片方向 → 决定换序或坐标变换 → 写雅可比；见[第10章](10_重积分.md#iterated)。
- <strong style="color:#16A34A">级数：</strong>先看通项 → 结构匹配判别法 → 幂级数端点分别检查；见[第12章](12_无穷级数.md#positive)。

## 易混名词入口

| 易混对象 | 区分要点 |
|---|---|
| 极限与函数值 | 极限看趋近过程，函数值看点上取值 |
| 可导与连续 | 可导推出连续，连续不推出可导 |
| \(dy\) 与 \(\Delta y\) | \(dy\) 是线性主部，\(\Delta y\) 是真实增量 |
| 定积分与不定积分 | 定积分是数值累积，不定积分是一族原函数 |
| 驻点与极值点 | 驻点只是候选点，还需符号或二阶判别 |
| 收敛半径与收敛区间 | 半径只给内部范围，端点必须另查 |
