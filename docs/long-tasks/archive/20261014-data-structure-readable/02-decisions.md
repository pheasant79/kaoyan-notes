# Decisions

## 2026-10-14 — 知识库结构

- Choice: 总览/名词索引 + 八章文件 + 章内知识锚点。
- Rationale: 支持从名词定位到具体解释，同时保留章节上下文，避免一个名词一个文件造成碎片化。

## 2026-10-14 — 内容深度

- Choice: 中等完整。
- Rationale: 保留定义、关系、实现、算法、条件、复杂度、性质和必要短例子，不写完整代码和长证明。

## 2026-10-14 — 视觉规则

- Choice: Markdown + 少量行内 HTML；蓝色核心、绿色方法、红色限制、紫色关联。
- Rationale: 适配 VS Code，颜色帮助扫描但不依赖颜色传达唯一信息。

## 2026-10-14 — 比较表

- Choice: 只在有实际选择价值的章节使用。
- Rationale: 第2、4、6、7、8章存在重要方法差异；第1、3、5章不为统一格式硬加表格。
