第7章 输入输出系统

本章问题：外部设备怎样在速度和格式不同的情况下与主机交换数据？

本章知识树

  • I/O 接口：数据、状态、控制寄存器
  • 程序查询：CPU 主动轮询
  • 中断：设备就绪后通知 CPU
  • DMA：控制器直接在设备与主存间搬运数据

先看结论

  1. 接口负责缓冲、状态反馈、控制命令和设备时序适配。
  2. 程序查询简单但占用 CPU；中断适合间歇事件；DMA 适合大块数据。
  3. DMA 仍需总线仲裁，完成后通常以中断通知 CPU。

结构图：三种 I/O 路径

方法比较

方式谁主动适用特点
程序查询CPU简单设备、数据量小

DMADMA 控制器连续大块数据

易错与边界

中断不是设备直接执行指令；CPU 仍需保存现场并运行服务程序。DMA 减少 CPU 搬运次数，但不等于完全不占用总线。

跨章节连接

I/O 接口通过总线访问主存，DMA 与存储系统共享地址和数据通路，中断进入 CPU 控制流程。
