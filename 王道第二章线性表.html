1 本章主线：先逻辑，后存储，再操作

线性表这一章不是在教“某一个 C 语言结构体”，而是在教一个完整套路：

本章学习顺序线性表定义 → 线性表基本操作 → 顺序表实现 → 单链表实现 → 双链表/循环链表 → 操作复杂度与题型。

2 线性表的定义

线性表是具有相同数据类型的 n 个数据元素的有限序列。记作：

L = (a1, a2, a3, ..., ai, ..., an)
关键词含义为什么重要
相同数据类型表中元素属于同一类方便统一处理和存储
有限序列元素个数有限，且有前后顺序不是集合，顺序有意义
除第一个外都有直接前驱ai 前面是 a(i-1)体现一对一关系
除最后一个外都有直接后继ai 后面是 a(i+1)体现线性关系
纠偏：线性表不是“顺序逻辑”那么窄线性表的逻辑是“线性关系”，也就是一对一前后相邻。它可以顺序存储，也可以链式存储。不要把“线性表”直接等同于“顺序表”。
一句话线性表是逻辑结构：它只说元素排成一条线，不规定这条线在内存里怎么摆。

3 线性表 ADT：为什么抽象也有操作？

王道里的 InitList、ListInsert、ListDelete 不是 C 语言内置函数，而是抽象数据类型 ADT 的操作名。

操作含义顺序表如何做链表如何做
InitList初始化空表分配数组，长度置 0建立头结点或空指针
ListInsert插入元素移动后续元素改指针
ListDelete删除元素移动后续元素断开并释放节点
GetElem按位取值数组下标 O(1)从头遍历 O(n)
LocateElem按值查找顺序扫描顺序扫描
你三年没见过 InitList 的原因你用过它的思想，只是没用过这个名字。Python 的 []、C++ 的 vector 构造、Java 的 new ArrayList() 都是在做“初始化线性表”。
一句话抽象线性表规定“应该有哪些操作”；具体顺序表/链表决定“操作怎么实现”。

4 顺序表：数组 + 长度 + 操作规则

顺序表是线性表的顺序存储实现。核心特点是：逻辑相邻，物理也相邻。

typedef struct { int data[MaxSize]; int length; } SqList;
纠偏：顺序表就是数组吗？不完全是。顺序表底层通常是数组，但顺序表还包含长度和操作规则。裸数组像一排空格子，顺序表像“有管理制度的一排格子”。

5 顺序表操作：考研重点是移动次数

插入

在第 i 个位置插入 e，需要把第 i 到第 n 个元素整体后移。

for (j = L.length; j >= i; j--) L.data[j] = L.data[j - 1]; L.data[i - 1] = e; L.length++;

删除

删除第 i 个元素，需要把第 i+1 到第 n 个元素整体前移。

for (j = i; j < L.length; j++) L.data[j - 1] = L.data[j]; L.length--;
操作最好情况最坏情况平均情况
按位查找O(1)O(1)O(1)
按值查找O(1)O(n)O(n)
插入O(1)，插尾O(n)，插头O(n)
删除O(1)，删尾O(n)，删头O(n)
考研抓手顺序表题目常考“移动多少个元素”。插入第 i 个位置移动 n-i+1 个；删除第 i 个位置移动 n-i 个。

6 单链表：节点 + 指针串起来

单链表是线性表的链式存储实现。核心特点是：逻辑相邻，物理不要求相邻。

typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;
纠偏：LinkList 是系统给的吗？不是。LinkList 是你用 typedef 起的别名，等价于 LNode *。它只是为了让“头指针”读起来像“链表”。
带头结点 vs 不带头结点王道常用带头结点，优点是插入/删除第一个元素时不用额外特殊判断。头结点不是第一个有效数据元素。

7 单链表操作：考研重点是改指针顺序

插入：在 p 后插入 s

s->next = p->next; p->next = s;

顺序不能反。先让新节点接住后半段，再让前半段接住新节点。

删除：删除 p 的后继节点 q

q = p->next; p->next = q->next; free(q);
操作单链表复杂度原因
按位查找O(n)必须从头数过去
按值查找O(n)必须逐节点比较
已知前驱插入/删除O(1)只改指针
已知某节点但不知道前驱，删除它通常 O(n)单链表不能直接回到前驱
纠偏：LNode *p = L->next这句话不是“结构体等于 next”。p 是指针变量，L->next 也是指针值，所以它只是把“首元结点地址”复制给 p。

8 双链表、循环链表、静态链表

类型结构特点解决什么问题代价
双链表prior + data + next可以向前找前驱多一个指针空间，修改更复杂
循环单链表尾节点 next 指回头结点从任意节点可绕回表头判断结束条件变化
循环双链表头尾互连，双向循环插入删除边界更统一指针维护更多
静态链表数组模拟链表，游标代替指针无指针语言也能实现链式思想空间预先固定
// 双链表节点 typedef struct DNode { int data; struct DNode *prior, *next; } DNode;
考研抓手双链表插入删除常考指针修改顺序；循环链表常考“判空”和“尾指针找表头/表尾”的便利性。

9 复杂度与题型总表

结构按位查找按值查找插入删除适合场景
顺序表O(1)O(n)O(n)随机访问多，插删少

王道第二章常见题型

顺序表移动次数链表指针修改顺序带头结点判空头插法/尾插法逆置链表删除特定值节点合并两个有序表

做题路线先判断逻辑结构是线性表，再判断存储结构是顺序还是链式，最后问自己：这题真正考的是“移动元素”还是“改指针”。

10 你那些疑问应该放在本章哪里？

你的问题属于第二章哪块结论
InitList 是 C 语言吗？线性表 ADT不是内置，是教材操作名
线性表抽象，为什么有函数？ADT 与实现分离抽象规定操作，实现负责代码
顺序表是不是数组？顺序表用数组实现，但还要有 length 和规则
动态分配是不是伪数组？顺序表动态分配不是，堆区真实连续空间，指针存首地址
C 的 & 和 C++ 引用C/C++ 语法补丁C 取地址；C++ 声明中的 & 可表示引用
LinkList 是系统定义吗？单链表类型定义不是，是 LNode* 的别名
LNode *p = L->next链表指针操作把 next 里的地址复制给 p
结构体能不能 ==C 语言补丁C 不自动定义结构体相等，需逐字段比较
最重要的纠偏第二章不是在证明“数据结构常不常用”，而是在训练你把“抽象逻辑关系”翻译成“两类存储实现”。C 语言代码只是王道用来表达这个翻译过程的工具。
