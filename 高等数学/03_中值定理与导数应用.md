## 先看结论

- <strong style="color:#DC2626">中值定理先查条件：</strong>闭区间连续、开区间可导是最常见的两项前提。
- <strong style="color:#2563EB">一阶导数看增减：</strong>$f'(x)>0$ 对应递增，$f'(x)<0$ 对应递减。
- <strong style="color:#16A34A">极值要看符号变化：</strong>驻点只是候选点，$f'$ 左右符号改变才可判极值。
- <strong style="color:#16A34A">二阶导数看凹凸：</strong>二阶导数变号才可能形成拐点。
- <strong style="color:#9333EA">闭区间最值：</strong>区间内部临界点和两个端点都不能漏。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:28px 0 16px;">

## 1. 中值定理：从局部导数到整体增量

<a id="mean-value"></a>

<a id="rolle"></a>

### 罗尔定理

若 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，且 $f(a)=f(b)$，则存在 $\xi\in(a,b)$，使

$$
f'(\xi)=0.
$$

<strong style="color:#16A34A">使用信号：</strong>题目给出两个端点函数值相等，或要求证明某点导数为零。

<a id="lagrange"></a>

### 拉格朗日中值定理

在同样的连续、可导条件下，存在 $\xi\in(a,b)$，使

<div style="background:#F8FAFC;border-left:3px solid #2563EB;padding:10px 14px;margin:14px 0;">
<strong style="color:#2563EB">核心公式</strong>

$$
f'(\xi)=\frac{f(b)-f(a)}{b-a}.
$$

<strong style="color:#2563EB">作用：</strong>把区间平均变化率连接到某个点的瞬时变化率。

<strong style="color:#DC2626">成立条件：</strong>$f$ 在闭区间连续、开区间可导。

<strong style="color:#16A34A">使用信号：</strong>证明单调性、不等式、函数估计或两个函数恒等关系。

<strong style="color:#DC2626">易错点：</strong>不能只看到“可导”就直接套用，闭区间端点的连续性也要确认。
</div>

<a id="cauchy"></a>

### 柯西中值定理

若 $f,g$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，则存在 $\xi\in(a,b)$ 使

$$
\bigl[f(b)-f(a)\bigr]g'(\xi)=\bigl[g(b)-g(a)\bigr]f'(\xi).
$$

它是拉格朗日定理的推广，也常作为洛必达法则的理论基础。

<strong style="color:#DC2626">条件边界：</strong>若将结论改写成两个商相等，还须确认分母不为零；交叉相乘形式不需要额外的除法条件。

### 泰勒公式

<a id="taylor"></a>

若 $f$ 在包含 $x_0$ 与 $x$ 的区间上有直到 $n+1$ 阶的连续导数，则存在介于二者之间的 $\xi$，使

$$
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k
+\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}.
$$

前半部分是泰勒多项式，最后一项是拉格朗日型余项。求极限时按所需精度保留足够阶数；若要断定无穷级数等于原函数，还需另查余项趋零，见[第12章](12_无穷级数.md#taylor)。

## 2. 一阶导数：单调性与极值

<a id="monotonicity"></a>

### 单调性

在区间内若 $f'(x)>0$，则 $f$ 严格递增；若 $f'(x)<0$，则 $f$ 严格递减。实际做题时先求定义域，再用驻点和不可导点把定义域分段。

### 极值判定

若内点 $x_0$ 处可导且取得局部极值，则费马定理给出 $f'(x_0)=0$。但反过来不成立，例如 $f(x)=x^3$ 在 $0$ 处导数为零，却没有极值。

<strong style="color:#16A34A">判定流程：</strong>

<div style="background:#F8FAFC;border-left:3px solid #16A34A;padding:10px 14px;margin:14px 0;line-height:1.8;">

求定义域 → 求 $f'$ → 找驻点和不可导点 → 按临界点分区 → 判断 $f'$ 符号是否改变 → 得到单调区间和极值。

</div>

## 3. 二阶导数：凹凸、拐点与渐近线

<a id="curvature"></a>

- $f''(x)>0$：图像向上凹；
- $f''(x)<0$：图像向下凹；
- 只有凹凸性在该点两侧发生改变时，才称该点为拐点。

水平渐近线看 $x\to\pm\infty$ 的极限；垂直渐近线看 $x\to a$ 时函数是否趋于无穷；斜渐近线要求 $f(x)-(kx+b)\to0$。

<strong style="color:#DC2626">边界：</strong>$f''(x_0)=0$ 只能说明二阶判别暂时失效，不能直接得出拐点或极值结论。

## 4. 闭区间最值

<a id="absolute-extrema"></a>

若 $f$ 在 $[a,b]$ 上连续，则一定能取得最大值和最小值。计算流程：

<div style="background:#F8FAFC;border-left:3px solid #16A34A;padding:10px 14px;margin:14px 0;line-height:1.8;">

求定义域和区间 → 找内部临界点 → 计算临界点函数值 → 计算 $f(a)$、$f(b)$ → 比较全部候选值。

</div>

## 5. 典型方法：导数应用题的统一入口

<a id="application-flow"></a>

| 题目目标 | 先求什么 | 判断依据 | 常见遗漏 |
|---|---|---|---|
| 单调区间 | $f'$ | $f'$ 的正负 | 忽略定义域断点 |
| 局部极值 | $f'$ 和临界点 | 符号是否改变 | 把驻点直接当极值 |
| 凹凸与拐点 | $f''$ | 凹凸是否改变 | $f''=0$ 就下结论 |
| 闭区间最值 | $f'$、端点 | 比较所有候选值 | 漏端点 |
| 不等式估计 | 中值定理 | 增量与导数联系 | 未检查连续可导条件 |

## 易错与边界

- 驻点、不可导点只是候选临界点。
- 单调性结论只能在定义域的连续区间内使用。
- 中值定理的 $\xi$ 存在，但通常不要求求出具体值。
- 闭区间最值和局部极值是不同概念。
- 洛必达属于极限方法，完整说明见第1章，不要把它当成导数应用的万能工具。
