王道计算机组成第一章 · 计算机系统概述

目标不是背名词，而是把“硬件部件、抽象层次、地址、字长、指令集、性能指标”放到同一张地图上。

1 本章总地图：你正在建立“计算机分层模型”

第一章最容易懵，因为它把很多后面章节才会细讲的东西提前摆出来：CPU、主存、I/O、指令、操作系统、虚拟机、性能指标。它不是要你马上精通，而是先给你一张地图。

学习姿势第一章不要追求把每个硬件电路细节一次吃完。先记住：CPU 执行指令，主存放指令和数据，I/O 连接外设，ISA 是软件和硬件的共同语言。

2 五大部件：不是五个盒子，而是五种职责

冯·诺依曼计算机的五大部件是：运算器、控制器、存储器、输入设备、输出设备。其中运算器和控制器合在一起就是 CPU 的核心。

部件职责直觉类比
运算器进行算术运算和逻辑运算真正干活的计算器
控制器取指令、分析指令、发控制信号指挥调度员
存储器保存程序和数据仓库
输入设备把外部信息送入计算机键盘、鼠标、传感器
输出设备把计算结果送给外部显示器、打印机、蜂鸣器
一句话五大部件是功能划分，不一定对应现代电脑里五块独立芯片。

3 主存、辅存、RAM、ROM、I/O 的关系

纠偏：只有内存才是存储器吗？硬盘是不是 I/O 外设？在“存储器层次”里，硬盘/SSD 属于辅助存储器；在“CPU 直接访问模型”里，硬盘又常被归到外部设备/I/O 设备。两个说法角度不同，不矛盾。
名称典型设备CPU能否像读内存一样直接按地址读特点
主存RAM，内存条能，通过地址总线访问速度快，断电丢失
ROM/FlashBIOS/固件、单片机 Flash视体系结构而定常用于保存固件，断电不丢
辅存硬盘、SSD、U盘通常不能直接按主存地址访问容量大，速度慢，需通过 I/O 控制器读写
王道口径主存储器是 CPU 可直接访问的存储器；辅助存储器属于存储系统的一部分，但从 CPU 访问路径看，它经常表现为 I/O 设备。

4 主存模型：存储体、MAR、MDR

教材里的主存储器通常由存储体、MAR、MDR组成。这是一个逻辑模型，不等于你电脑里只有“一整根内存条”这么简单。

部件作用你该怎么想
存储体真正保存 0/1 信息的阵列仓库本体
MARMemory Address Register，保存要访问的地址仓库货架编号
MDRMemory Data Register，保存读出/写入的数据搬运箱
纠偏MAR/MDR 是主存和 CPU 交换信息时的接口寄存器模型。真实现代系统里，寄存器、缓存、内存控制器、总线协议更复杂，但教材先用这个模型把“按地址访问数据”讲清楚。

5 地址、指针、存储单元：三个概念别混

概念是什么在哪一层看
地址用于定位存储单元的编号硬件/体系结构层
物理地址真实主存位置的编号内存控制器/MMU之后
虚拟地址程序看到的地址操作系统+CPU地址转换层
指针高级语言里的变量，其值被解释为某个地址C/C++ 语言层
一句话地址是“编号”；指针是“存着编号的变量”。你在 C 里看到的指针值通常是虚拟地址，不一定是物理地址。

存储单元大小怎么理解？

现代通用计算机通常按字节编址：一个地址对应 1 字节。教材说“存储单元”时，可能指一个可寻址单元，也可能指一次读写的数据单元，要看上下文。

说法常见含义例子
按字节编址每个地址指向 1B地址 1000、1001 相差 1 字节
存储字一次从存储体取出的若干位32 位或 64 位数据
存储单元教材里常指按地址访问的基本单位具体大小由编址方式决定

6 字节、字、机器字长、32/64位

概念定义注意
字节 Byte8 bit现代计算机最常见的编址单位
字 WordCPU 一次自然处理的数据单位不同机器不同，常与机器字长相关
机器字长CPU 一次能直接处理的二进制位数常见为 32 位、64 位
32/64 位 CPU通常指通用寄存器宽度、整数运算宽度、虚拟地址能力等体系结构特征不是说内存“每格”就是 32/64 位
MAR 是不是 CPU 位数？MDR 呢？MAR 位数决定理论可寻址范围：MAR 有 n 位，最多表示 2^n 个地址。MDR 位数决定一次和主存交换多少位数据。它们可能和机器字长相同，也可能不同，不能简单划等号。
MAR = 32 位，按字节编址 → 最多 2^32 B = 4GB MAR = 36 位，按字节编址 → 最多 2^36 B = 64GB MDR = 64 位 → 一次可传 8B 数据

8 函数调用、栈、返回地址在这个框架里吗？

在，但第一章不会展开。函数调用属于“程序如何在机器上运行”的内容，会横跨指令系统、CPU、存储器、操作系统、编译原理。

你之后该怎么学王道计组后面学指令系统、CPU 时会更接近这个问题；操作系统会讲进程地址空间和栈；编译原理会讲函数调用约定。现在先知道：栈在主存中，PC 控制下一条指令，call/ret 改变 PC。

9 冯·诺依曼机、现代计算机、早期模型

弹幕说“这是很早期的结构”，有道理，但不能因此忽略。王道讲的是抽象结构，不是现代 CPU 的完整物理图。

层次教材模型现代现实
存储器主存 + MAR + MDR寄存器、L1/L2/L3 Cache、内存控制器、虚拟内存
CPU执行取指、分析、执行流水线、乱序执行、分支预测、多核
I/O输入设备、输出设备总线协议、DMA、中断、驱动、设备控制器
为什么还学老模型因为老模型是现代复杂系统的骨架。现代 CPU 很复杂，但它仍然要执行指令、访问存储、控制 I/O。考研先考骨架，不先考每根神经。

10 软件、硬件、ISA、汇编语言

应用软件和系统软件

类型例子职责
应用软件微信、浏览器、游戏、你的业务程序直接服务用户需求
系统软件操作系统、编译器、数据库、驱动程序管理硬件资源，为应用提供运行环境
驱动程序显卡驱动、声卡驱动、网卡驱动系统软件的一类，负责让 OS 和设备通信

软硬件逻辑功能等价性

“同一操作可由软件实现，也可由硬件实现”不是说软件脱离硬件运行，而是说某个功能可以做成专门电路，也可以用通用 CPU 执行一串指令来完成。

功能软件实现硬件实现
乘法循环加法或库函数CPU 内置乘法器
加密普通指令跑算法AES 专用指令/加速器
图像处理CPU 程序处理像素GPU/专用芯片处理

ISA 与汇编

ISA 是 Instruction Set Architecture，指令集体系结构。它规定机器能识别哪些指令、有哪些寄存器、地址怎么表示、指令格式是什么。

纠偏：电脑不会乘法，我写 C 为什么不报错？C 语言不是直接等于硬件指令。编译器会根据目标 ISA 翻译：如果硬件有乘法指令，就生成乘法指令；如果没有，就生成一段等效代码或调用库函数。
ISR / ISA 小心别混你这里大概率看到的是 ISA，不是 ISR。ISA 是指令集体系结构；ISR 常指 Interrupt Service Routine，中断服务程序。汇编语言随 ISA 变化，比如 x86 汇编和 ARM 汇编写法不同。

11 微程序机器 M0 到虚拟机器：为什么一层套一层？

王道把计算机看成多级层次，是为了说明：越往上越接近人，越往下越接近硬件。

层次名字它看到的“机器”靠什么实现
M0微程序机器微指令级机器硬件或微程序控制器
M1传统机器机器语言机器由 M0 解释/执行机器指令
操作系统机器扩展机器带文件、进程、系统调用的机器操作系统
M2汇编语言机器能读汇编的机器汇编程序翻译成机器语言
M3高级语言机器能读 C/Java/Python 的机器编译器/解释器/虚拟机
一句话所谓“虚拟机器”不是一定指 VMware，而是指：下层机器通过翻译或解释，让上层用户感觉自己在使用一台更好用的新机器。

12 性能指标：数据通路带宽为什么像 CPU 位数？

数据通路带宽指数据通路一次能并行传送的数据位数，比如 32 位、64 位。它确实和“CPU 一次处理多少位”很像，但二者不是永远相等。

指标说明容易混淆点
机器字长CPU 一次能处理的数据位数偏运算能力
MDR 位数一次与主存交换的数据位数偏访存数据宽度
MAR 位数能表示多少个地址偏寻址范围，不是传数据宽度
数据通路带宽数据通路一次能传多少位偏部件之间的数据流宽度
总线带宽单位时间传输的数据量位宽 × 频率，常以 B/s 表示
总线带宽 = 总线宽度 × 总线频率 例如：64 bit × 100 MHz = 8 B × 100M = 800 MB/s
纠偏“能传多少数据”看 MDR/数据通路/数据总线宽度；“能寻址多大空间”看 MAR/地址总线宽度。MAR 管地址范围，MDR 管一次搬多少数据。
