# 第4章 线性方程组

> **本章要解决的问题：** 方程组何时有解、解有多少，以及怎样写出通解？

## 本章知识树

```text
线性方程组 Ax=b
├─ 消元：增广矩阵 → 阶梯形
├─ 相容性：r(A) 与 r(A|b)
├─ 齐次组：基础解系与通解
└─ 非齐次组：特解 + 齐次通解
```

## 先看结论

- <strong style="color:#2563EB">核心：</strong>方程组有解 \(\Longleftrightarrow r(A)=r(A\mid b)\)。
- <strong style="color:#2563EB">核心：</strong>齐次方程组总有零解；若 \(r(A)=n\)，则只有零解。
- <strong style="color:#16A34A">方法：</strong>先对增广矩阵消元，再根据主元和自由变量写解。
- <strong style="color:#2563EB">关系：</strong>非齐次通解 = 一个特解 + 对应齐次方程组的通解。
- <strong style="color:#DC2626">注意：</strong>未知数个数 \(n\) 与秩 \(r\) 的差 \(n-r\) 是自由变量个数，不是解的个数。

## <a id="solution-structure"></a>1. 结构与秩判定

非齐次方程组写成

$$Ax=b,$$

其中 \(A\) 是系数矩阵，\((A\mid b)\) 是增广矩阵。基本判定为

$$
\begin{cases}
r(A)<r(A\mid b)&\Rightarrow\text{无解},\\
r(A)=r(A\mid b)=n&\Rightarrow\text{唯一解},\\
r(A)=r(A\mid b)<n&\Rightarrow\text{无穷多解}.
\end{cases}
$$

## <a id="elimination"></a>2. 高斯消元

把增广矩阵化为阶梯形：

1. 选择主元并交换到合适位置；
2. 用主元消去其下方元素；
3. 检查是否出现 \([0\ \cdots\ 0\mid c]\) 且 \(c\ne0\)；
4. 从最后一个主元开始回代，或用自由变量参数化。

<strong style="color:#16A34A">核心思想：</strong>消元改变方程的写法，但保持解集不变。

### 短例：由阶梯形直接读出通解

若消元后得到

$$
\left\{
\begin{aligned}
x_1+2x_3&=1,\\
x_2-x_3&=2,
\end{aligned}
\right.
$$

取自由变量 \(x_3=t\)，则

$$
x_1=1-2t,\qquad x_2=2+t.
$$

因此

$$
x=
\begin{pmatrix}1\\2\\0\end{pmatrix}
+t\begin{pmatrix}-2\\1\\1\end{pmatrix}.
$$

第一项是一个特解，第二项给出对应齐次方程组的基础解方向。

## 3. 齐次方程组

齐次组 \(Ax=0\) 至少有零解。若 \(r(A)=r<n\)，则有 \(n-r\) 个自由变量，可取相应基础解系，通解为基础解系的线性组合。

非齐次方程组有一个特解 \(x_0\) 时，通解为

$$x=x_0+x_h,$$

其中 \(x_h\) 是对应齐次方程组的通解。

## 4. 方法比较

| 目标 | 推荐方法 | 关键判断 |
|---|---|---|
| 判断有无解 | 比较 \(r(A)\) 与 \(r(A\mid b)\) | 两个秩是否相等 |
| 求唯一解 | 高斯消元或逆矩阵 | \(r(A)=n\) |
| 求无穷多解通解 | 阶梯形 + 自由变量参数化 | 自由变量个数 \(n-r\) |
| 讨论参数 | 分参数取值讨论主元 | 参数可能改变秩 |

## 易错与边界

- 判定无解要比较 \(r(A)\) 和 \(r(A\mid b)\)，不能只看系数矩阵。
- 基础解系不是任意一组解；它必须能线性表示齐次解空间中的所有解，并且线性无关。
- 非齐次通解中的“特解 + 齐次通解”不是两个任意解相加。
- 齐次方程组有非零解的条件是 \(r(A)<n\)，不是“方程个数少于未知数”这一条表面条件本身。
