# 考研英语一 70+ 学习系统

适用对象：2027 年 12 月参加考研英语一，目标 70+；语法有基础但不熟练，词汇背过但遗忘明显，阅读尚未系统做真题。

## 每天怎么用

1. 打开 `D:\24213\Documents\考研\outputs\english70_study_system\考研英语一70+学习追踪表.xlsx`。
2. 在「每日记录」填今天的学习内容和分钟数。
3. 做阅读时，把影响理解的词放进「真题词表」。
4. 卡住的长难句放进「长难句拆解」。
5. 做错的题按「错题诊断」记录：定位句、你的误解、错因、下次规则。
6. 每周末看「总览」和「阶段路线」，调整下一周任务。

## 第一件事：基线测试

先找一篇旧年份英语一阅读，不查词，计时完成。做完后记录：

- 用时
- 5 道题的答案
- 哪些句子完全读不懂
- 哪些词影响理解
- 每题为什么选

然后把错题按这个格式发给我：

`2010 Text1 第2题，我的答案是A，正确答案是C。`

我会按「定位 → 你的答案从哪来 → 错因归类 → 教训总结」给你诊断。

## 题源原则

- 真题是核心：只用来研究考研命题逻辑，不要被普通阅读题替代。
- 分级阅读负责量：ReadTheory / British Council / VOA 用来补词汇、句子和阅读耐力。
- AI 题只当辅助：可以练理解，但不能替代真题手感。
