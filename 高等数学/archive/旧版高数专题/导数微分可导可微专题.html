导数、微分、可导与可微专题

目标很简单：以后你看到 f'(x)、dy、dx、可导、可微，不再把它们混成一锅粥。

1先给结论：四个词各管什么

概念一句话符号你可以怎么理解
导数变化率f'(x)，dy/dxy 随 x 变化得多快
微分线性主部dy=f'(x)dxx 变一点点时，y 大约变多少
可导导数存在f'(x0) 存在这一点有明确切线斜率
可微能用线性函数近似增量Δy=AΔx+o(Δx)这一点附近可以用一条直线近似
一元函数最重要结论 对一元函数而言：在某点可导 ⇔ 在某点可微。并且如果可导，那么微分就是 dy=f'(x)dx。
但是多元函数不一样 多元函数里，“偏导数存在”不一定可微。考研多元微分学特别爱考这个区别。

2什么是导数：变化率的极限

设 y=f(x)。当 x 从 x0 变到 x0+Δx 时，函数值从 f(x0) 变到 f(x0+Δx)。

Δx = x - x0 Δy = f(x0 + Δx) - f(x0) 平均变化率 = Δy / Δx 导数 = 瞬时变化率 f'(x0) = lim(Δx→0) [Δy / Δx] = lim(Δx→0) [f(x0+Δx)-f(x0)] / Δx
平均变化率 看一段区间上的总体变化，像“平均速度”。
瞬时变化率 把区间缩到无限小，得到某一点的变化率，像“瞬时速度”。

3什么是微分：函数增量的线性主部

导数是一个数或函数，微分是一个“增量表达式”。如果 y=f(x) 在 x 处可导，那么：

dy = f'(x) dx

这里 dx 是自变量 x 的微小增量，dy 是用线性近似算出来的 y 的主要变化量。

真实增量： Δy = f(x+Δx)-f(x) 微分： dy = f'(x)Δx 当 Δx 很小时： Δy ≈ dy
微分的关键词：近似 微分不是说真实变化量永远等于 f'(x)dx，而是说当 dx 很小时，函数变化的主要部分是 f'(x)dx。

4导数和微分的区别

比较导数微分
核心含义变化率变化量的线性主部
典型符号f'(x)，dy/dxdy=f'(x)dx
结果形态一个数或一个函数含 dx 的表达式
问的问题y 随 x 变得多快x 变一点点，y 主要变多少
例子y=x² → y'=2xdy=2x dx
导数像“倍率” 在 x=3 处，y=x² 的导数是 6，意思是 x 小变一下，y 约按 6 倍变化。
微分像“估算变化” 若 x=3 且 dx=0.01，则 dy=6×0.01=0.06。
例：y = x²，在 x=3 处，x 增加 0.01 导数：y' = 2x，所以 y'(3)=6 微分：dy = 6dx = 6×0.01 = 0.06 真实增量：Δy = 3.01² - 3² = 0.0601 微分 dy=0.06 是真实增量 Δy=0.0601 的近似。

5几何意义：导数看斜率，微分看切线增量

导数的几何意义 f'(x0) 是曲线 y=f(x) 在点 x0 处的切线斜率。
微分的几何意义 dy=f'(x0)dx 是沿着切线走 dx 后，纵坐标增加的量。

6可导是什么意思：导数存在

函数在 x0 处可导，就是下面这个极限存在：

f'(x0) = lim(Δx→0) [f(x0+Δx)-f(x0)] / Δx

极限存在的意思是：左边靠近和右边靠近得到同一个有限值。

不可导原因典型图像例子
尖点左右斜率不同f(x)=|x| 在 0 处不可导
竖直切线斜率趋于无穷f(x)=x^(1/3) 在 0 处导数无穷，不可导
间断函数值跳了分段函数跳跃点不可导
剧烈振荡极限不稳定某些振荡函数在点处不可导
一元判断顺序 先看连续，再看左右导数。若不连续，一定不可导；若连续，还要继续看左右导数是否相等。

7可微是什么意思：能被线性函数很好近似

在一元函数中，y=f(x) 在 x0 处可微，意思是函数增量可以写成：

Δy = AΔx + o(Δx)

其中 AΔx 是主要的线性部分，o(Δx) 是比 Δx 更小的误差。若可微，那么这个 A 就是导数 f'(x0)。

若 f 在 x0 处可微： Δy = f'(x0)Δx + o(Δx) 所以： dy = f'(x0)dx
把可微想成“局部像直线” 可微不是说函数本身是直线，而是说在这个点非常非常近的地方，它可以被切线近似。

8可导与可微的关系：一元函数里等价

对一元函数，这是必须背熟的结论：

一元函数： 可导 ⇔ 可微 并且： dy = f'(x)dx
条件能推出什么注意
可导一定连续、一定可微可导是很强的条件
可微一定可导、一定连续一元函数里可微和可导等价
连续不一定可导|x| 在 0 连续但不可导
不可导不一定不连续可能连续但有尖点
强弱关系： 可导/可微 ⇒ 连续 ⇒ 有定义 反过来一般不成立： 连续 ⇏ 可导 有定义 ⇏ 连续

9一元和多元差异：考研最爱挖坑

你现在先学一元导数，但后面学多元函数时一定要注意：多元函数里“偏导存在”和“可微”不是一回事。

对象一元函数多元函数
导数/偏导存在可导等价于可微偏导存在不一定可微
可微含义能用一条直线近似能用一个平面近似
判断重点左右导数是否相等偏导、连续性、全增量极限
常见结论可导 ⇒ 连续可微 ⇒ 连续；偏导连续 ⇒ 可微
多元函数记住这句 偏导存在只是说明沿 x 轴、y 轴两个方向能算斜率；可微要求所有方向合起来都能被同一个线性平面近似，要求更强。

10典型例子：用例子把概念钉住

例 1：y=x²

导数： y' = 2x 微分： dy = 2x dx 在 x=3 处： y'(3)=6 dy=6dx

例 2：y=|x| 在 0 处

左导数： lim(x→0-) (|x|-0)/(x-0) = -1 右导数： lim(x→0+) (|x|-0)/(x-0) = 1 左右导数不相等，所以 x=0 处不可导。 一元函数中不可导也就不可微。

例 3：y=sin x

导数： y' = cos x 微分： dy = cos x dx 在 x=0 处： y'(0)=1 dy=dx

11考研题怎么判断：固定流程

1先看点
是在某点还是区间？
2看连续
不连续一定不可导
3看左右导数
分段、绝对值优先左右算
4写结论
一元可导即可微
题目说法你该想到
函数在某点可导该点连续，左右导数相等，可微
函数在某点连续不能推出可导，要警惕尖点
函数在某点可微一元中立刻推出可导，且 dy=f'(x)dx
求微分先求导，再乘 dx
求近似值用 f(x0+Δx)≈f(x0)+f'(x0)Δx
一元函数做题口诀： 求导数：先定自变量，再求变化率。 求微分：先求导数，再乘 dx。 判可导：先连续，再左右导数。 判可微：一元等价于可导，多元不能这么粗暴。

12常见误区：你现在最容易卡在这里

误区 1：把 dy/dx 看成普通分数 初学时可以借助分数直觉，但正式理解是导数符号。微分换元能这么写，是因为链式法则保证成立。
误区 2：以为 dy=Δy 一般不相等。Δy 是真实增量，dy 是线性近似主部。
误区 3：连续就可导 错。|x| 在 0 处连续，但不可导。
误区 4：可导和可微永远等价 一元函数等价；多元函数里，偏导存在不等于可微。
误区 5：求微分忘记乘 dx y=x² 的导数是 2x，微分是 2x dx。
误区 6：看到 x' 不问自变量 x' 必须先补全：是 dx/dt，还是 dx/dy，还是 dx/dx？
最终记忆版 导数回答“变得多快”；微分回答“变一点点大约变多少”；可导回答“导数存不存在”；可微回答“能不能用线性近似”。一元函数里，可导和可微是同一件事的两种说法。
