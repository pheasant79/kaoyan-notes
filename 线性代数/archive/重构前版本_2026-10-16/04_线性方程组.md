## 先看结论

- <strong style="color:#2563EB">核心：</strong>方程组有解 $\Longleftrightarrow r(A)=r(A\mid b)$。
- <strong style="color:#2563EB">核心：</strong>齐次方程组总有零解；若 $r(A)=n$，则只有零解。
- <strong style="color:#16A34A">方法：</strong>先对增广矩阵消元，再根据主元和自由变量写解。
- <strong style="color:#2563EB">关系：</strong>非齐次通解 = 一个特解 + 对应齐次方程组的通解。
- <strong style="color:#DC2626">边界：</strong> $n-r$ 是自由变量个数，不是解的个数。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="model"></a>
## 1. 从方程组到矩阵模型

线性方程组写成

$$Ax=b,$$

其中 $A$ 是系数矩阵，$x$ 是未知向量，$b$ 是常数向量。把 $b$ 拼到 $A$ 的右侧得到增广矩阵 $(A\mid b)$。

从向量角度看，$Ax=b$ 的含义是：$b$ 能否由 $A$ 的列向量组线性表示。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="rank-judgement"></a>
## 2. 秩判定：先判断解的类型

对 $n$ 个未知数的非齐次方程组：

$$r(A)<r(A\mid b)\Rightarrow\text{无解}.$$

$$r(A)=r(A\mid b)=n\Rightarrow\text{唯一解}.$$

$$r(A)=r(A\mid b)<n\Rightarrow\text{无穷多解}.$$

<strong style="color:#DC2626">判断顺序：</strong>不能只看 $r(A)$，必须同时比较系数矩阵和增广矩阵的秩。

<a id="elimination"></a>
## 3. 高斯消元：把解结构显出来

基本流程：

1. 选择主元，必要时交换行；
2. 用主元消去下方元素，得到阶梯形；
3. 检查是否出现 $[0\ \cdots\ 0\mid c]$ 且 $c\ne0$；
4. 从最后一个主元回代，或给自由变量参数化。

<span style="color:#16A34A"><strong>核心思想：</strong></span>初等行变换改变方程的写法，但不改变解集。

### 短例：从阶梯形直接写通解

若消元后得到

$$x_1+2x_3=1,\qquad x_2-x_3=2,$$

取自由变量 $x_3=t$，则

$$x=\begin{pmatrix}1\\2\\0\end{pmatrix}+t\begin{pmatrix}-2\\1\\1\end{pmatrix}.$$

<span style="color:#CA8A04"><strong>读法：</strong></span>第一项是一个特解，第二项是齐次解空间中的方向。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="homogeneous"></a>
## 4. 齐次方程组：基础解系与自由变量

齐次组 $Ax=0$ 至少有零解。若 $r(A)=r<n$，则有 $n-r$ 个自由变量，可取 $n-r$ 个线性无关解作为基础解系，通解为它们的线性组合。

<strong style="color:#DC2626">边界：</strong>“方程个数少于未知数”只能作为直观提示，严格判断仍需比较秩。

<a id="nonhomogeneous"></a>
## 5. 非齐次方程组：特解加齐次通解

若 $x_0$ 是 $Ax=b$ 的一个特解，$x_h$ 是 $Ax=0$ 的通解，则

$$x=x_0+x_h$$

就是非齐次方程组的通解。

## 6. 典型方法

<a id="methods"></a>

| 目标 | 操作顺序 | 关键条件 |
|---|---|---|
| 判断有无解 | 求 $r(A)$、$r(A\mid b)$ | 两个秩是否相等 |
| 求唯一解 | 消元或逆矩阵 | $r(A)=n$ |
| 求无穷多解通解 | 阶梯形 + 自由变量参数化 | 自由变量数 $n-r$ |
| 讨论参数 | 分参数取值求主元 | 参数可能改变秩 |

## 7. 易错与边界

- 无解的标志是增广矩阵出现矛盾行，等价于 $r(A)<r(A\mid b)$。
- 基础解系必须线性无关，并能表示齐次解空间中的所有解。
- “特解 + 齐次通解”中的特解必须确实满足非齐次方程组。
- 自由变量的数量是维数，不是解的总数；无穷多解时解的个数仍然是无限的。
