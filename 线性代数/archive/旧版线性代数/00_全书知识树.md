## 公式与方法入口

### 公式索引

| 公式/概念 | 主章节 | 作用与关键条件 |
|---|---|---|
| \(|A|\ne0\) | [第1章](01_行列式.md#cramer) | 方阵可逆、齐次方程组只有零解 |
| \(A^{-1}=\frac1{|A|}A^*\) | [第2章](02_矩阵.md#inverse) | 伴随矩阵求逆，要求 \(|A|\ne0\) |
| \(r(A)=r(A^T)\) | [第2章](02_矩阵.md#rank) | 行秩与列秩相等 |
| \(Ax=b\) | [第4章](04_线性方程组.md#solution-structure) | 用秩判断相容性与解的结构 |
| \(Ax=\lambda x\) | [第5章](05_特征值与特征向量.md#definition) | 定义特征值与特征向量 |
| \(P^{-1}AP=\Lambda\) | [第5章](05_特征值与特征向量.md#similarity) | 相似对角化，要求有足够多无关特征向量 |
| \(f(x)=x^TAx\) | [第6章](06_二次型.md#definition) | 用矩阵表示二次型 |
| \(x^TAx>0\) | [第6章](06_二次型.md#positive-definite) | 正定性的定义，要求对所有非零 \(x\) 成立 |

### 方法选择入口

- 行列式：性质变换、按行列展开、克拉默法则；
- 矩阵：逆矩阵、初等变换、秩、矩阵方程；
- 向量组：线性表示、相关性、极大无关组；
- 方程组：消元、秩判定、基础解系与通解；
- 特征值：特征方程、相似对角化、实对称矩阵；
- 二次型：配方法、正交变换、正定判别。

## 易混名词入口

| 易混对象 | 区分要点 |
|---|---|
| 行列式与矩阵 | 行列式是一个数，矩阵是数表；只有方阵有通常意义下的行列式 |
| 行等价、相似、合同 | 分别服务于消元求秩、特征结构、二次型 |
| 线性相关与能否表示 | 相关性研究零组合；能否表示研究目标向量是否在生成空间中 |
| 齐次与非齐次方程组 | 齐次右端为零，始终有零解；非齐次可能无解 |
| 代数重数与几何重数 | 前者是特征根在多项式中的重复次数，后者是特征子空间维数 |
| 正定与可逆 | 正定矩阵一定可逆，但可逆矩阵不一定正定 |

<strong style="color:#DC2626">边界提醒：</strong>“秩相等”“可逆”“满秩”“有唯一解”经常互相联系，但它们的适用对象和前提不同，正文中会分开解释。
