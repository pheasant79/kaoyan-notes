存储元、存储单元与 X/Y 双译码器

专门解决：到底是“存储元”存 1bit，还是“存储单元”存 1bit；以及双译码器怎样在存储矩阵中选中数据。

1 谁存 1 bit？

直接结论存储元存储 1 bit，也就是一个二进制位：0 或 1。

存储单元不是通常意义上的 1 bit，而是由若干个存储元组成的一组二进制位。一个存储单元可以存 8 bit、16 bit、32 bit、64 bit，具体看机器和教材设定。

名词大小作用类比
存储元1 bit保存一个 0 或 1一个小开关/小电容
存储单元若干 bitCPU 按地址访问的一组数据一个有编号的格子
存储体很多存储单元真正存放大量数据的阵列整片仓库
最容易错的地方如果题目说“一个存储单元由 8 个存储元组成”，意思就是：这个存储单元能存 8 bit = 1 byte。不是“存储单元自己只存 1 bit”。

2 存储元、存储单元、存储体的结构关系

层级从小到大是：

存储元（1 bit） → 存储单元（若干 bit） → 存储体（很多存储单元） → 主存储器（存储体 + MAR + MDR）
关键区别“存储元”强调物理存储 0/1 的最小元件；“存储单元”强调被地址选中的一组位；“存储体”强调很多单元构成的整体阵列。

3 X/Y 双译码器：为什么不用一根线选全部地址？

如果存储体很大，直接用一个译码器选中所有存储单元，线路会很长、很复杂。所以常把地址分成两部分：

地址 = X 行地址 + Y 列地址

X 译码器选中某一行，Y 译码器选中某一列。行和列交叉处的存储元或存储单元就被选中。

过程发生了什么
1. 地址进入地址被拆成 X 部分和 Y 部分
2. X 译码X 译码器选中一行
3. Y 译码Y 译码器选中一列
4. 行列交叉交叉处的存储元/存储单元被选中
5. 读/写读出数据到 MDR，或把 MDR 中的数据写入
别误解X/Y 双译码器不是“地址的一种新含义”。它只是硬件内部为了更高效地从二维矩阵中选位置，把一串地址位拆成行号和列号。

4 它和 MAR/MDR 怎么接起来？

完整读主存过程可以这样看：

CPU 给地址 → MAR 保存地址 → 地址译码器选中存储单元 → 存储单元的数据送入 MDR → CPU 取走数据
最终统一存储元存 1 bit；若干存储元组成一个存储单元；MAR 里的地址经过 X/Y 译码器选中某个存储单元；该单元的数据通过 MDR 和 CPU 交换。
