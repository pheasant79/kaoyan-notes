## 目录结构

- 根目录的 `*_目录总图.md` 是各学科入口，负责连接知识树和章节。
- 各学科目录包含一份全书知识树或总览，以及按章节组织的 Markdown 正文。
- 章节配图使用本地 SVG，放在所属学科的 `assets/chXX/` 目录中，并由正文引用。

## 阅读与维护

- 按“学科总入口 → 全书知识树 → 章节正文”的路径定位和复习。
- 正文使用 Markdown；文档之间和图片使用相对路径链接，不写依赖本机目录的绝对路径。
- 新增或调整章节后，同步检查全书知识树、根目录入口、章节链接和图片引用。
- 新增或移动 SVG 后，确认正文引用路径有效，并保留图题及必要的文字说明。
