# Decisions

## 2026-10-15 — 先确认教材边界
- Question: 是否直接按常见数学二章节生成？
- Choice: 暂不生成正式正文；先取得用户正在使用的教材目录。
- Rationale: 不同教材会合并或拆分行列式、矩阵、向量、方程组、特征值和二次型；先确认可以避免章节错位和返工。
- Affected nodes: LA-1, LA-2
- Reversible: yes

## 2026-10-15 — 采用公开资料建立初始范围
- Question: 在用户未提供教材目录时，先按什么范围启动？
- Choice: 采用考研数学二常见六块：行列式、矩阵、向量组、线性方程组、特征值与特征向量、二次型。
- Rationale: 公开教材目录和考试资料均覆盖这组主干；后续仍以用户教材为准微调章节拆分。
- Affected nodes: LA-1, LA-2, LA-3
- Reversible: yes
