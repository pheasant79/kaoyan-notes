## 先看结论

- <strong style="color:#2563EB">核心：</strong>$\beta$ 能由 $\alpha_1,\ldots,\alpha_s$ 表示，当且仅当 $Ax=\beta$ 有解，其中 $A$ 以这些向量为列。
- <strong style="color:#2563EB">核心：</strong>向量组无关，当且仅当对应齐次方程组只有零解。
- <strong style="color:#16A34A">方法：</strong>把向量组组成列矩阵，用行变换求秩并定位主元列。
- <strong style="color:#2563EB">关系：</strong>极大无关组的个数等于向量组秩，也等于列矩阵的秩。
- <strong style="color:#DC2626">边界：</strong>表示存在性和表示唯一性是两个问题，后者还要求生成向量组线性无关。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="combination"></a>
## 1. 线性组合与表示

若

$$\beta=k_1\alpha_1+\cdots+k_s\alpha_s,$$

则称 $\beta$ 可由向量组 $\alpha_1,\ldots,\alpha_s$ 线性表示。把这些向量按列组成矩阵 $A$，就得到

$$Ax=\beta.$$

因此，“能否表示”本质上是一个线性方程组是否有解的问题。

<span style="color:#16A34A"><strong>判断入口：</strong></span>组成列矩阵 $A$ → 比较 $r(A)$ 与 $r(A\mid\beta)$。

<a id="uniqueness"></a>
## 2. 表示的存在性与唯一性

若 $r(A)=r(A\mid\beta)$，则 $\beta$ 至少有一种表示。若列向量组还线性无关，则表示唯一。

- **存在性**只问“有没有系数”；
- **唯一性**还要求生成向量组无关；
- 若生成向量组相关，同一个向量可能有多组系数。

<strong style="color:#DC2626">易错：</strong>“能表示”不能直接推出“表示唯一”。含有重复向量或冗余向量时，通常会出现多种表示。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="dependence"></a>
## 3. 线性相关与无关

若

$$k_1\alpha_1+\cdots+k_s\alpha_s=0$$

只有全零解，则向量组线性无关；存在不全为零的系数使等式成立，则线性相关。

把向量组作为列矩阵 $A$，则

$$r(A)=s\Longleftrightarrow \alpha_1,\ldots,\alpha_s\text{线性无关}.$$

在 $n$ 维空间中，向量个数超过 $n$ 时必相关；但具体题目仍应通过秩或齐次方程组判断。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="max-independent"></a>
## 4. 极大无关组

极大无关组同时满足：

1. 其中向量线性无关；
2. 原向量组中的每个向量都能由它表示。

对列矩阵作行变换，主元列的位置可以确定原矩阵中的极大无关组。注意：**应回到原矩阵取对应列，不能直接把行变换后的列当作原向量。**

<a id="rank"></a>
## 5. 向量组的秩

向量组的秩是极大无关组所含向量的个数。极大无关组可能不唯一，但其向量个数唯一。

$$\operatorname{rank}(\alpha_1,\ldots,\alpha_s)=r(A).$$

这里的“秩”完整解释属于本章；矩阵章只使用矩阵秩，方程组章使用秩判定解结构。

### 短例：快速识别相关性

$$
\alpha_1=\begin{pmatrix}1\\0\\1\end{pmatrix},\quad
\alpha_2=\begin{pmatrix}0\\1\\1\end{pmatrix},\quad
\alpha_3=\begin{pmatrix}1\\1\\2\end{pmatrix}.
$$

因为 $\alpha_3=\alpha_1+\alpha_2$，所以三向量相关，秩为 $2$。

<hr style="border:0;border-top:1px solid #D1D5DB;margin:26px 0 16px;">

<a id="methods"></a>
## 6. 典型方法

1. **判断能否表示：**比较 $r(A)$ 与 $r(A\mid\beta)$。
2. **判断相关性：**求列矩阵秩；秩小于向量个数则相关。
3. **求极大无关组：**行化简找主元列位置，再回原矩阵取列。
4. **判断唯一性：**先确认表示存在，再检查生成向量组是否无关。

## 7. 易错与边界

- 两两不成比例只是直观条件，不足以保证整个向量组无关。
- 极大无关组不一定唯一，但其个数唯一。
- 向量组秩不是向量个数，也不是矩阵元素个数。
- 主元列位置由行变换确定，主元列本身应从原矩阵取得。
