# Decisions

## 已确认

- 现有正式范围为第1至第8章；第二章样张作为全书基准。
- 其余7章需要先审查，再重排和制图。
- 全书总览与根入口同步更新。
- 章节大分区前使用浅灰细分隔线；不改变标题层级，不给每个小标题加线。
- 每章制作关键过程图，按需要控制数量，不为凑数制图。
- 内容采用“保留主干并深度重排”，不是只做样式统一，也不是无边界扩写。
- 质量优先，先交诊断和拟定知识树，用户确认后再成稿。

## 模型与推理建议

- 诊断与终审：使用当前可用的高能力推理模型，推理强度取最高档。
- 分章成稿：使用同一高能力模型的高档推理强度；若受额度或等待时间影响，可只对事实审查和算法条件使用最高档。
- 模型只影响分析覆盖度、长链条一致性和审查稳定性，不能代替教材范围核对、复杂度条件检查、链接检查和真实预览。
