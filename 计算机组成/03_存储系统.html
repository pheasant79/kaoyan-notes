第3章 存储系统

本章问题：数据怎样从地址进入存储层次，并在需要时被快速取出？

本章知识树

  • 存储元 → 存储单元 → 存储体
    • 地址译码、MAR、MDR
    • 芯片位宽与容量扩展
  • 存储层次
    • Cache 映射与替换
    • 虚拟地址、页表、TLB

先看结论

  1. 容量=单元数×每单元位数；位扩展增加字长，字扩展增加单元数。
  2. MAR 送地址，MDR 暂存数据，地址通路和数据通路不能混淆。
  3. Cache 利用时间局部性和空间局部性降低平均访问时间。
  4. 虚拟地址经转换得到物理地址，再访问主存或 Cache。

结构图：一次主存访问

地址线决定“找哪里”，数据线决定“搬什么”。

典型方法

地址 → 译码器 → 选中行/列 → 存储阵列 → 数据线 → MDR；读写控制信号决定动作方向。

已有专题图：存储元与双译码器、MDR 与位线、多存储体、虚拟存储器。

易错与边界

Cache 命中不等于主存不存在；TLB 缓存地址转换结果；高位交叉与低位交叉的地址分配不能混用。

跨章节连接

CPU 的访存指令提供地址，总线承担地址、数据和控制信号传输。
