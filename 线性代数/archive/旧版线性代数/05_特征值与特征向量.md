# 第5章 特征值与特征向量

> **本章要解决的问题：** 哪些方向经过矩阵作用后方向不变，只改变一个倍数？

## 本章知识树

```text
特征值与特征向量
├─ 定义：Ax=λx
├─ 求法：\(|\lambda I-A|=0\)，再解 \((A-\lambda I)x=0\)
├─ 相似与对角化：换基寻找更简单表示
└─ 实对称矩阵：特征值实、特征向量可正交
```

## 先看结论

- <strong style="color:#2563EB">核心：</strong>\(\lambda\) 是 \(A\) 的特征值，当且仅当 \(|\lambda I-A|=0\)。
- <strong style="color:#16A34A">方法：</strong>先求特征值，再对每个特征值解齐次方程求特征向量。
- <strong style="color:#2563EB">核心：</strong>有 \(n\) 个线性无关特征向量时，矩阵可相似对角化。
- <strong style="color:#2563EB">关系：</strong>特征值之和等于迹，特征值之积等于行列式（按代数重数计）。
- <strong style="color:#DC2626">注意：</strong>特征向量不能取零向量；同一特征值的特征向量连同零向量构成特征子空间。

## <a id="definition"></a>1. 定义与求法

若存在非零向量 \(x\)，使

$$Ax=\lambda x,$$

则称 \(\lambda\) 为特征值，\(x\) 为对应特征向量。移项得

$$
(A-\lambda I)x=0.
$$

要有非零解，必须满足

$$|A-\lambda I|=0.$$

这一步得到特征方程；代回后再求特征向量。

若 \(A\) 为 \(n\times n\) 矩阵，特征多项式为 \(n\) 次多项式，因此在复数范围内有 \(n\) 个特征根（按代数重数计）。实矩阵的特征根未必全部为实数，但实对称矩阵一定如此。

## 2. 特征值与特征向量的计算流程

1. 写出 \(|A-\lambda I|=0\)，求全部特征值；
2. 对每个 \(\lambda_i\)，解 \((A-\lambda_iI)x=0\)；
3. 写出对应特征向量的通解，取出线性无关向量；
4. 根据线性无关特征向量的总数判断能否对角化。

## <a id="similarity"></a>3. 相似与对角化

若存在可逆矩阵 \(P\)，使

$$P^{-1}AP=B,$$

则称 \(A\) 与 \(B\) 相似。相似矩阵有相同的特征多项式、特征值、行列式和迹。

若 \(A\) 有 \(n\) 个线性无关特征向量，令这些向量为 \(P\) 的列，则

$$P^{-1}AP=\Lambda,$$

其中 \(\Lambda\) 为对角矩阵。

## 4. 短例：二阶矩阵的特征结构

设

$$
A=\begin{pmatrix}2&1\\1&2\end{pmatrix}.
$$

特征方程为

$$
|A-\lambda I|=(2-\lambda)^2-1=\lambda^2-4\lambda+3=0,
$$

所以 \(\lambda_1=3,\lambda_2=1\)。分别解

$$
(A-3I)x=0,\qquad (A-I)x=0,
$$

可取特征向量 \((1,1)^T\) 与 \((1,-1)^T\)。它们线性无关，因此 \(A\) 可相似对角化；由于 \(A\) 对称，这两个方向还彼此正交。

## <a id="symmetric"></a>5. 实对称矩阵

实对称矩阵的特征值都是实数，不同特征值对应的特征向量彼此正交，并且存在正交矩阵 \(Q\) 使

$$Q^TAQ=\Lambda.$$

这里的正交相似变换是二次型化标准形的重要基础。

## 6. 方法比较

| 问题 | 先看什么 | 结论 |
|---|---|---|
| 求特征值 | 特征方程 \(|A-\lambda I|=0\) | 得到可能的 \(\lambda\) |
| 求特征向量 | \((A-\lambda I)x=0\) | 得到对应特征子空间 |
| 判断可对角化 | 线性无关特征向量总数 | 达到 \(n\) 才能对角化 |
| 实对称矩阵 | 正交特征向量 | 可用正交矩阵对角化 |

## 易错与边界

- 特征值重复不等于不能对角化，关键要看线性无关特征向量的数量。
- 相似变换使用 \(P^{-1}AP\)；二次型标准化常用合同变换 \(P^TAP\)，两者目的和保持量不同。
- 代数重数是特征根在特征多项式中的重复次数；几何重数是对应特征子空间的维数，几何重数不超过代数重数。
- 特征向量求出后可以任意取非零倍数，但不能取零向量。
