## 公式索引

| 公式/概念 | 主章节 | 作用与关键条件 |
|---|---|---|
| \(|A|\ne0\) | [行列式](01_行列式.md#invertibility) | 方阵可逆，齐次方程组只有零解 |
| \(A^{-1}=\dfrac{1}{|A|}A^*\) | [矩阵](02_矩阵.md#inverse) | 伴随矩阵求逆，要求 \(|A|\ne0\) |
| \(r(A)=r(A^T)\) | [矩阵](02_矩阵.md#rank) | 行秩与列秩相等 |
| \(Ax=b\) | [方程组](04_线性方程组.md#model) | 用秩判断相容性和解结构 |
| \(Ax=\lambda x\) | [特征值](05_特征值与特征向量.md#definition) | 特征值与特征向量定义 |
| \(P^{-1}AP=\Lambda\) | [特征值](05_特征值与特征向量.md#diagonalization) | 相似对角化，要求有 \(n\) 个无关特征向量 |
| \(f(x)=x^TAx\) | [二次型](06_二次型.md#representation) | 用矩阵表示二次型 |
| \(x^TAx>0\) | [二次型](06_二次型.md#positive-definite) | 对所有非零 \(x\) 成立才是正定 |

## 方法入口

- [行列式计算](01_行列式.md#methods)：先制造零，再展开或化三角形。
- [矩阵求秩与求逆](02_矩阵.md#methods)：统一使用初等行变换。
- [向量组判断](03_向量组.md#methods)：把向量组作为列矩阵，比较秩和主元列。
- [方程组判断](04_线性方程组.md#methods)：先比较秩，再处理自由变量和通解。
- [特征值计算](05_特征值与特征向量.md#methods)：先特征方程，再解特征子空间。
- [二次型判别](06_二次型.md#methods)：按题目要求选择配方法、合同变换或正交变换。

## 易混名词

| 对象 | 区分要点 | 主要解释位置 |
|---|---|---|
| 行列式 / 矩阵 | 一个数 / 数表 | [第1章](01_行列式.md#definition) |
| 行秩 / 向量组秩 / 方程组秩 | 矩阵结构 / 向量独立信息 / 解结构判定 | [第2章](02_矩阵.md#rank) |
| 行等价 / 相似 / 合同 | 消元求秩 / 特征结构 / 二次型 | [第2章](02_矩阵.md#relations) |
| 能否表示 / 表示唯一 | 存在性 / 还需生成向量组无关 | [第3章](03_向量组.md#uniqueness) |
| 代数重数 / 几何重数 | 特征根重复次数 / 特征子空间维数 | [第5章](05_特征值与特征向量.md#multiplicity) |
| 标准形 / 规范形 | 保留具体系数 / 只看正负零结构 | [第6章](06_二次型.md#canonical) |
| 正定 / 可逆 | 正定一定可逆，可逆不一定正定 | [第6章](06_二次型.md#positive-definite) |

<span style="color:#DC2626"><strong>边界提醒：</strong></span>
看到“秩相等”“满秩”“可逆”“唯一解”时，先确认对象是矩阵、向量组还是方程组，再套用结论。
