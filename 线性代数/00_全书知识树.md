## 公式与判据索引

| 公式/判据 | 主要用途 | 正文 |
|---|---|---|
| $\lvert A\rvert\ne0\Longleftrightarrow A$ 可逆 | 方阵可逆性 | [第1章](01_行列式.md#invertibility) |
| $r(A)=$ 阶梯形主元数 | 求秩 | [第2章](02_矩阵.md#rank) |
| $\beta$ 可表示 $\Longleftrightarrow r(A)=r(A\mid\beta)$ | 判断表示存在性 | [第3章](03_向量组.md#existence) |
| 表示唯一 $\Longleftrightarrow$ 存在且生成组无关 | 判断系数是否唯一 | [第3章](03_向量组.md#uniqueness) |
| $Ax=b$ 有解 $\Longleftrightarrow r(A)=r(A\mid b)$ | 方程组相容性 | [第4章](04_线性方程组.md#rank-judgement) |
| $\dim\ker(A)=n-r(A)$ | 齐次解空间维数 | [第4章](04_线性方程组.md#homogeneous) |
| $\lvert A-\lambda I\rvert=0$ | 求特征值 | [第5章](05_特征值与特征向量.md#definition) |
| $P^{-1}AP=\Lambda$ | 相似对角化 | [第5章](05_特征值与特征向量.md#diagonalization) |
| $Q^TAQ=\Lambda,\ Q^{-1}=Q^T$ | 实对称矩阵正交对角化 | [第5章](05_特征值与特征向量.md#symmetric) |
| $f(x)=x^TAx$ | 二次型矩阵表示 | [第6章](06_二次型.md#representation) |
| $p+q=\operatorname{rank}(A)$ | 惯性指数与秩 | [第6章](06_二次型.md#canonical) |
| $x^TAx>0\;(x\ne0)$ | 正定性 | [第6章](06_二次型.md#positive-definite) |

## 方法入口

- [行列式计算](01_行列式.md#methods)：先辨别求值、判零、判可逆或解方程。
- [矩阵求秩/求逆](02_矩阵.md#methods)：先化阶梯形或写 $(A\mid I)$。
- [向量组判断](03_向量组.md#methods)：组成列矩阵，比较秩并回原矩阵取主元列。
- [方程组判断](04_线性方程组.md#methods)：先比较 $r(A)$ 与 $r(A\mid b)$，再参数化。
- [特征值计算](05_特征值与特征向量.md#methods)：特征方程 → 特征子空间 → 重数比较。
- [二次型判别](06_二次型.md#methods)：按目标选择配方法、合同变换、正交变换或正定判据。
