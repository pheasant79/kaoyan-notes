考研英语前缀后缀记忆教程 阅读实战版

不是词源百科，是考场上能马上用的那种：先看词性，再看方向，最后用上下文收口。

一句话总纲 前缀多管“方向、态度、数量”，后缀多管“词性、功能、语气”。
阅读用途 先靠词缀判断大概义，再用上下文验证，不要只背中文意思。
记忆方法 按“否定、位置、数量、关系、名词、形容词、动词”分组，比零散背单词稳得多。

0总规则：词缀不是主角，但它很会帮你省时间

核心判断顺序 先看 后缀 判词性，再看 前缀 判方向，最后看 词根 + 上下文 定具体含义。
prefix → root → suffix → context 先改方向 给核心意思 定词性/功能 最后纠偏
前缀最常做什么 否定反向位置数量关系

前缀像“方向键”，最常见的是把核心意思改个方向，例如 legal 到 illegal，regular 到 irregular。

后缀最常做什么 词性名词形容词动词副词

后缀更像“身份证”，它告诉你这个词在句子里通常是什么身份，常常比中文意思更值得先看。

考研阅读里的真实用法 你不用把所有词缀背成字典，只要能在选项里迅速看出：这个词大概率是“否定的、相反的、过多的、再一次的、形容某种倾向的”就够了。

1否定 / 反向前缀：一看到它，先怀疑“不是、反过来、取消”

这一组最适合阅读猜义，因为它们经常直接影响正反关系。

前缀核心意思常见词判断口诀提醒
un-不、反unfair, unhappy, unlock最像“反义开关”多用于形容词/动词
in-/im-/il-/ir-不、无inactive, impossible, illegal, irregular看后面首字母做变体别只认 in- 一种写法
non-非、没有nonprofit, nonverbal“不是这一类”比 un- 更像分类排除
dis-否定、分离、撤销dislike, disappear, disconnect有时是“不”，有时是“分开”常和动作、关系有关
de-去掉、降低、否定devalue, decrease, deactivate常有“往回、往下、去除”感觉别硬翻成单纯“不”
anti-反对、抵抗antiwar, anti-inflammatory带立场色彩多见于名词和形容词
counter-反向、对抗counterattack, counterargument“顶回去、对着干”常见于正式表达
别偷懒 dis- 不总是“否定”，de- 也不总是“取消”。阅读里先抓大方向，再看句子是不是在说“拆开、减少、撤回、对抗”。

2方向 / 位置前缀：空间感很强，容易帮助你记词义

前缀核心意思常见词图像感阅读提示
sub-下、次、从属subway, subsoil, subordinate往下压一层常带“次级、附属”
super-/supra-上、超、在上方superior, supernatural, supranational抬高一层也可表示“超过”
inter-之间、互相international, interaction两边之间拉线看到“互相、跨界”就想到它
intra-内部、之内intramural, intracellular往里圈和 inter- 正好相反
trans-横过、转移、跨越transport, transform, transfer从一边到另一边非常常见，别忽视
ex-外、前任exit, export, ex-president从里面出去常见“前任”义
extra-额外、外部extraordinary, extracurricular框外加一层“超出正常范围”
pre-在前、预先preview, prefix, prepay时间向前挪阅读里常是“提前”
post-在后、后来的postwar, postgraduate时间向后挪常表阶段顺序
快速联想 把它们记成四条轴：sub-/super- 是上下轴，inter-/intra- 是内外轴， trans-/ex-/extra- 是穿出与外扩轴，pre-/post- 是时间前后轴。

3数量 / 程度前缀：考试里很爱考“多少、几次、过头了没”

前缀核心意思常见词判断口诀提醒
mono-单一monologue, monochrome一个常和“独立、单色”有关
bi-/di-两个、双bicycle, bilingual, dioxide两个一起看bi- 更常见于英语词
tri-三个triangle, tricycle三角、三轮一眼就能抓到
multi-多multiple, multimedia一堆、一组比 poly- 更口语常见
poly-多、复合polytechnic, polymer很多部分拼起来学术感更强
semi-半、部分semifinal, semicircle一半常和比赛、形状搭配
over-过度、太多overwork, overload超过正常线常带负面评价
under-不足、在下方underestimate, underground不够、偏低既有“位置”也有“程度”
hyper-过度、亢进hyperactive, hypersensitive太猛了医学、科技语境常见
hypo-低于、过少hypoglycemia, hypodermic偏低和 hyper- 形成对照
数量主线

先按数轴记：mono- 一个，bi-/di- 两个，tri- 三个，multi-/poly- 是很多个，semi- 是一半。

程度主线

再按程度轴记：over- 和 hyper- 都偏“过头”，under- 和 hypo- 都偏“低/少”。

常见误区 under- 不只表示“下面”，在阅读里更常是“低估、不足、低于标准”；hyper- 与 hypo- 则是一组“高/低”对照。

4行为 / 关系前缀：动作感很强，适合抓逻辑

前缀核心意思常见词阅读感受提醒
re-再、回、重新review, reuse, rebuild做一遍、往回拉有时是“重复”，有时是“恢复”
co-/com-/con-共同、一起cooperate, combine, connect合在一起动注意拼写变体
pro-向前、支持progress, promote, pro-environment往前推、站队支持既有方向也有立场
mis-错误地mistake, misunderstand, mislead做歪了和“错误认知”关系很大
auto-自己、自动autobiography, automatic自己驱动常见于科技和身份类词汇
tele-远、远程telephone, television, telework隔着距离传递科技英语里很常见
一个好记法 这组可以按“动作关系”记：re- 是回放/重做，co-/com-/con- 是合拍一起动， pro- 是往前推/站队支持，mis- 是走偏，auto- 是自驱，tele- 是远程。

5名词后缀：看见它们，先想“这是个名词”

后缀常见功能常见词大致意义阅读提醒
-tion/-sion动作/结果/状态relation, decision做出来的结果最常见的名词后缀之一
-ment行为、结果development, improvement发展、完成后的东西常见抽象名词
-ness性质、状态happiness, darkness“某种状态”形容词变名词很典型
-ity性质、能力、状态ability, reality性质变抽象概念书面感强
-ism主义、现象、倾向capitalism, criticism一套观点或风格阅读里常带立场
-ist人、专家、信奉者scientist, artist“某类人”和 -ism 常配对
-er/-or人、物、执行者teacher, actor, supervisor做动作的人/物高频、好认
-ship状态、关系、身份friendship, leadership关系或职位状态抽象感强
-hood时期、身份、群体childhood, neighborhood一个阶段或关系圈不如前几个高频，但很稳
名词后缀快速记 先把它们分成四簇记：-tion/-sion 和 -ment 是“动作落地后的结果”； -ness 和 -ity 是“把性质抽成概念”；-ism 和 -ist 是“主义 + 信奉者”； -er/-or、-ship、-hood 是“人/角色/关系/阶段”。

6形容词后缀：它们往往直接告诉你“这个词在修饰谁”

后缀常见功能常见词大致印象提醒
-ive有……性质的active, sensitive倾向、性质阅读里很高频
-al……的，相关的natural, national属性相关常把名词拉成形容词
-ous充满……的dangerous, various量感、特征感常带书面感
-ful充满的，富有的helpful, careful满满的特征常是正面或中性
-less没有……的hopeless, careless缺失感明显负向
-able/-ible可以……的readable, visible可行、可被处理非常适合阅读猜义
-ic……的，相关的economic, dramatic学术/抽象经常出现在学术文章里
-ary相关的，属于……的primary, customary类别感不如 -al 直观
-ent/-ant处于……状态的different, important性质固定化有时也可作名词
形容词后缀快速记 这组别按单个背，按“性质簇”背更顺：-ive、-al、-ous、-ic、-ary、-ent/-ant 都是在给名词挂“某种属性”；-ful/-less 是“有/没有”；-able/-ible 是“能不能”。
词性先行 看到这些后缀时，先把整个词当作形容词，别急着翻成具体中文；真正的褒贬和强弱，再交给上下文判断。

7动词与副词后缀：它们告诉你“这个词怎么动、怎么说”

后缀常见功能常见词阅读印象提醒
-ize/-ise使……化、使……成为organize, realize, modernize把东西变成某种状态英美拼写有差异
-ify使成、使……化simplify, clarify把复杂变简单常见于学术和说明文
-en使……变得widen, strengthen变化感不少词很高频
-ate使、成为、做activate, separate, investigate动作感强动词后缀里很重要
-ly副词，……地quickly, largely修饰动作也可出现在部分形容词里
-ward(s)朝着……方向forward, backward, toward(s)方向感很强常和空间、时间有关
-wise在……方面；以……方式clockwise, otherwise方式/角度阅读里常见于复合表达
动词与副词后缀快速记 先分两簇：-ize/-ise、-ify、-en、-ate 是“把东西变成另一种状态”的使动簇； -ly、-ward(s)、-wise 是“怎么做/朝哪儿/从什么角度看”的方式簇。

8易混专题：考场上最容易被它们带偏

dis- vs de-

dis- 更像“不、分离、取消”；de- 更像“去掉、降低、往回撤”。

例：disconnect 是断开，decrease 是减少，devalue 是贬值。

in- 表否定 vs 表进入

in- 有时表示“不”，有时表示“进入、在……里面”。别看见就硬翻。

例：inaccurate 是不准确，include 是包含，inject 是注入。

-able vs -ible

两个都常表示“可以……的”，但 -able 更常见，-ible 更偏正式和书面。

例：readable, understandable, visible, accessible。

-ic vs -ical

都常作形容词后缀，-ical 往往更像“……方面的、带某种特征的”。

例：economic / economical，historic / historical。

最重要的提醒 词缀只能给你“高概率方向”，不能替代上下文。尤其在长难句里，先靠词缀缩小范围，再回句子验证。

9阅读猜词流程：四步就够

1. 看后缀：先判词性 2. 看前缀：再判方向 3. 拆词根：抓核心意思 4. 回句子：用上下文修正
示范 1

disagreement = dis-（否定） + agree（同意） + -ment（名词） = 分歧。

示范 2

international = inter-（之间） + nation（国家） + -al（形容词） = 国际的。

一条实战经验 看到陌生词，不要立刻查词典，先试着拆成“前缀 + 词根 + 后缀”。很多考研阅读里的长词，拆完就能猜个七八成。

11最后收口：你真正要记住的不是表，而是套路

前缀

改方向，改态度，改数量。

后缀

定词性，定功能，定抽象程度。

上下文

决定最终意思，不让词缀“单独作主”。

适合考研阅读的记法 记前缀时按“否定、位置、数量、关系”分组；记后缀时按“名词、形容词、动词、副词”分组。这样你不是在背碎片，而是在搭词感。

适用方式：直接双击打开即可。建议先通读一遍，再拿真题阅读里不会的词做拆解练习。
