## 公式与判据索引

| 公式/判据 | 主要用途 | 正文 |
|---|---|---|
| \(|A|\ne0\Longleftrightarrow A\) 可逆 | 判断方阵可逆性 | [第1章](01_行列式.md#invertibility) |
| \(r(A)=\) 阶梯形主元数 | 求矩阵或向量组秩 | [第2章](02_矩阵.md#rank) |
| \(Ax=b\) 有解 \(\Longleftrightarrow r(A)=r(A\mid b)\) | 判断方程组相容性 | [第4章](04_线性方程组.md#rank-judgement) |
| \(x=x_0+x_h\) | 写非齐次方程组通解 | [第4章](04_线性方程组.md#nonhomogeneous) |
| \(|A-\lambda I|=0\) | 求特征值 | [第5章](05_特征值与特征向量.md#definition) |
| \(P^{-1}AP=\Lambda\) | 判断并构造相似对角化 | [第5章](05_特征值与特征向量.md#diagonalization) |
| \(f(x)=x^TAx\) | 表示二次型 | [第6章](06_二次型.md#representation) |
| \(x^TAx>0\;(x\ne0)\) | 判断正定性 | [第6章](06_二次型.md#positive-definite) |

## 方法入口

- [行列式计算](01_行列式.md#methods)：先判断是求值、判零还是判可逆，再选择展开、制造零或化三角。
- [矩阵求秩/求逆](02_矩阵.md#methods)：先统一用初等行变换，再检查主元、可逆性和变换对象。
- [向量组判断](03_向量组.md#methods)：组成列矩阵，比较秩、主元列和表示条件。
- [方程组判断](04_线性方程组.md#methods)：先比较两个秩，再区分无解、唯一解和无穷多解。
- [特征值计算](05_特征值与特征向量.md#methods)：特征方程 → 特征子空间 → 重数比较 → 对角化判断。
- [二次型判别](06_二次型.md#methods)：按题目要求选择配方法、合同变换、正交变换或正定判据。
