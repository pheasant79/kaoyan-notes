先看结论

  1. 补码加法按位相加，最高位进位丢弃；有符号溢出看符号是否异常变化。
  2. 补码减法转为加法：A-B=A+(-B)。
  3. 浮点数范围主要由阶码决定，精度主要由尾数决定。
  4. 浮点运算经历对阶、尾数运算、规格化和舍入。

结构图：位模式如何变成数

同一串 0、1 的含义取决于数据类型和指令约定。

典型方法

补码减法：写出减数补码 → 按位相加 → 丢弃最高进位 → 检查溢出。

浮点加法：对阶 → 尾数加减 → 规格化 → 舍入 → 检查阶码。

易错与边界

补码最小负数没有相反数；无符号溢出和有符号溢出判断不同；指数范围大不等于有效数字精度高。
