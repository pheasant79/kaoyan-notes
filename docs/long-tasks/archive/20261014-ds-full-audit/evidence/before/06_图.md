# 第6章 图

> **本章要解决的问题：** 怎样表示多对多关系，并分别解决遍历、连通、路径和依赖问题？

<span style="color:#2563EB"><strong>一句话主线：</strong></span>
图的概念 → 存储结构 → BFS/DFS 遍历 → 按任务选择生成树、最短路径、拓扑排序或关键路径算法。

[返回全书总览](00_全书总览.md)

## 先看结论

- <span style="color:#2563EB"><strong>必须掌握：</strong></span>图由顶点集合 `V` 和边集合 `E` 构成；方向、权值、连通性是不同分类维度。
- <span style="color:#2563EB"><strong>必须掌握：</strong></span>邻接矩阵适合稠密图和快速判断边，邻接表适合稀疏图和枚举邻接点。
- <span style="color:#16A34A"><strong>必须掌握：</strong></span>先判断问题目标，再选算法：连通性用 BFS/DFS，覆盖代价用 Prim/Kruskal，路径代价用 Dijkstra/Floyd，依赖关系用拓扑排序/关键路径。
- <span style="color:#DC2626"><strong>必须掌握：</strong></span>Dijkstra 要求边权非负；拓扑排序要求有向无环；关键路径分析的是 AOE 网中的最长工期路径。

## 知识主线

```text
图的基本概念
→ 选择邻接矩阵或邻接表
→ 遍历图或建立遍历森林
→ 根据问题选择图算法
```

<a id="graph-basics"></a>
## 图的基本概念

图记为 `G = (V, E)`：

- 顶点表示对象；
- 边或弧表示对象之间的关系；
- 边权可以表示距离、费用、时间等。

以下用 `v` 表示顶点数，`e` 表示边或弧数。

### 分类维度

- **方向：** 无向边 / 有向弧；
- **权值：** 无权 / 带权；
- **可达性：** 连通、连通分量、强连通；
- **环：** 有向无环图 DAG 等。

有向图中，顶点有入度和出度；无向图中，顶点度数统计相连边的数量。

<a id="graph-storage"></a>
## 图的存储

### 邻接矩阵

用二维矩阵记录顶点对之间是否相邻或边权。

- 空间 `O(v²)`；
- 判断一条边是否存在通常为 `O(1)`；
- 枚举某顶点的邻接点通常为 `O(v)`；
- 适合较稠密图。

带权矩阵要区分“没有边”和“边权为 0”。

### 邻接表

每个顶点保存一个邻接点链表或类似结构。

- 空间 `O(v+e)`；
- 适合稀疏图；
- 枚举某顶点的邻接点只需遍历对应表；
- 查询任意指定边不保证 `O(1)`；
- 无向边通常在两个端点的表中各记录一次。

### 十字链表与邻接多重表

- **十字链表：** 一条有向弧同时接入弧尾的出边链和弧头的入边链。
- **邻接多重表：** 一条无向边结点同时接入两个端点的关联边链。

<a id="graph-traversal"></a>
## 图遍历

### BFS：广度优先搜索

从起点开始，先访问距离为 1 的顶点，再访问距离为 2 的顶点，使用队列维护待扩展顶点。

- 可得到 BFS 树；
- 在无权图或边权相同的图中，可求最少边数路径；
- 不能直接解决一般带权最短路径。

### DFS：深度优先搜索

沿着未访问邻接点不断深入，走不通时回溯。可以用递归或显式栈实现。

若图不连通，从一个起点不能访问全部顶点，需要从未访问顶点继续启动，得到遍历森林。

<a id="mst"></a>
## 最小生成树

目标：在**无向、带权、连通图**中，用 `v-1` 条边连接全部顶点，并使边权总和最小。

- **Prim：** 从已选顶点集合向外，反复选择跨越边界的最小权边。
- **Kruskal：** 按边权递增考虑边，只有不会形成环时才加入；通常用并查集判断是否同一连通分量。

不连通图不能生成覆盖全部顶点的一棵树，但可以讨论最小生成森林。

<a id="shortest-path"></a>
## 最短路径

### Dijkstra

解决单源最短路径。每次选当前距离最小且未确定的顶点，再用它松弛相邻边。

<span style="color:#DC2626"><strong>前提：</strong></span>边权必须非负；存在负权边时，Dijkstra 的贪心确定过程可能失效。

### Floyd

通过依次允许不同顶点作为中间点，更新所有点对之间的距离。

- 可处理负权边；
- 要求不存在导致最短路无下界的负权回路；
- 典型时间复杂度 `O(v³)`，距离表空间 `O(v²)`。

<a id="topological-sort"></a>
## 拓扑排序

拓扑排序处理有向无环图中的先后依赖：

1. 找到入度为 0 的顶点；
2. 输出它并删除它的出边；
3. 更新受影响顶点的入度；
4. 重复直到全部输出。

如果仍有顶点却找不到入度为 0 的顶点，说明图中有环。合法拓扑序可能不唯一。

**AOV 网：** 顶点表示活动，弧表示先后依赖。

<a id="critical-path"></a>
## 关键路径

**AOE 网：** 边表示带工期的活动，顶点表示事件。

常见分析过程：

1. 按拓扑序求事件最早发生时间；
2. 按逆拓扑序求事件最迟发生时间；
3. 计算活动的时间余量；
4. 余量为 0 的活动是关键活动，构成关键路径。

工程总工期由源到汇的最长路径决定，不是边数最多的路径。多源、多汇时可用零工期虚活动统一成一个源和一个汇。

<a id="algorithm-choice"></a>
## 重要方法比较

| 目标 | 典型算法 | 关键前提 | 核心思想 | 常见代价 |
|---|---|---|---|---|
| 访问全部顶点 | BFS / DFS | 图已建立存储 | 队列逐层 / 栈或递归深入 | 邻接表 `O(v+e)`，矩阵 `O(v²)` |
| 最小生成树 | Prim | 无向带权连通图 | 扩大顶点集合 / 按边权选边 | Prim 矩阵常为 `O(v²)`；Kruskal 常为 `O(e log e)` |
| 单源最短路 | Dijkstra | 边权非负 | 确定当前最近点并松弛 | 朴素实现 `O(v²)` |
| 全源最短路 | Floyd | 不存在负权回路 | 逐步允许中间点 | `O(v³)` |
| 先后依赖 | 拓扑排序 | 有向无环图 | 删除入度为 0 的顶点 | 邻接表可为 `O(v+e)` |
| 工程工期 | 关键路径 | AOE 网，通常统一源汇 | 最早/最迟时间与余量 | 邻接表实现可为 `O(v+e)` |

<a id="boundaries"></a>
## 易错与边界

- 生成树连接全部顶点但不一定总权最小；最小生成树也不保证任意两点间路径最短。
- BFS 既是遍历方法，也能解决无权最短路；不能把它简单说成“完全不是最短路算法”。
- 普通 DFS/BFS 不能直接得到有向图的全部强连通分量。
- 拓扑排序处理依赖关系，不是第8章按关键字大小排序。
- 缩短一条关键路径上的活动未必缩短总工期，因为可能还有其他同样关键的路径。
- 邻接矩阵和邻接表的复杂度必须绑定具体操作，不能只背一个“谁更快”。
